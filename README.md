# KIET University Website

## Description
This is a simple university website created for KIET (Karachi Institute of Economics and Technology) using HTML, CSS, and JavaScript.

## Features
- Home page with welcome message.
- About KIET University.
- List of university departments.
- Academic programs and degrees.
- Admission inquiry form.
- University image and video.
- Interactive welcome button.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Files
- `index.html` – Main website page.
- `style.css` – Website design.
- `script.js` – Button functionality.
- `123.jpg` – University image.
- `kiet.mp4` – University video.

## How to Run
1. Download the project.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your browser.

## Purpose
This project was created for learning basic web development.
